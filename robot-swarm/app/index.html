俯瞰カメラ (AprilTag 検出)

フィールド全体が映る位置にカメラ(Macのカメラ / iPhone連係カメラ / USBカメラ)を真上から向け、
右の「カメラ開始」を押してください。

マップ (クリックで目標を指定)

1. カメラ

ロボットの上面にタグを貼る: 1号機=ID1, 2号機=ID2, 3号機=ID3 (タグの上辺をロボットの前に)。

2. フィールド校正

ID10=左上 / ID11=右上 / ID12=右下 / ID13=左下 のタグの中心をフィールドの4隅に置いてボタンを押す。
またはカメラ映像上でフィールドの4隅を 左上→右上→右下→左下 の順にクリック。
フィールドの広さはパス画面の設定 () を使います。
