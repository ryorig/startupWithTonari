# SwarmBot 現状まとめ (2026-11-26)

災害現場での利用を想定した、ESP32 小型キャタピラロボット3台の群制御システム。
ブラウザ (Chrome) のアプリから Bluetooth で操作し、連結器で自由につないで一緒に走らせられる。

---

## 1. 機体

| 号機 | ボード | 役割 / センサー | スケッチ |
|---|---|---|---|
| 1号機 | XIAO ESP32S3 Sense | 確認担当・カメラ | `esp32/SwarmBot_XIAO_Cam/` |
| 2号機 | ESP32 DevKit | 熱探知・MLX90640 | `esp32/SwarmBot_ESP32_Thermal/` |
| 3号機 | ESP32 DevKit | 探索・VL53L1X 距離センサー (15cm で自動停止) | `esp32/SwarmBot_ESP32_ToF/` |

- 足まわり: 田宮 トラック&ホイールセット + ユニバーサルプレート、モータードライバ TB6612
- 号機の色: 1号機 = オレンジ / 2号機 = 緑 / 3号機 = 青
- 3本とも Mac の arduino-cli (esp32 core 3.3.12) でコンパイル成功

## 2. 連結器 (coupler_v9) — 全号機共通

- 部品: `hardware/coupler_v9/` (STL 9点 + 組立・配線メモ)。フック (サーボ付きゲート) とフォーク
- サーボ信号: DevKit = GPIO27 / XIAO = D7。**サーボは 5V (電池側) から給電、3V3 から取らない**
- 共通コード `SwarmCoupler.h` を3スケッチに同梱。動かした 0.7 秒後に PWM を止める (発熱対策)
- BLE コマンド: `K1` ロック / `K0` 解除 / `KA<度>` 角度指定 / `KL<度>` `KU<度>` ロック・解除角 / `K?` 状態問合せ → 通知 `K1` `K0`

## 3. アプリ (`app/`)

起動: `cd app && python3 -m http.server 8000` → Chrome で http://localhost:8000

### 画面
| タブ | できること |
|---|---|
| 操作 | 3台同時 / 1台ずつ / 個別 (3本のスティック) / **連結** (列ごとに連結を保って走る、仮想プレビュー付き)。1号機カメラ表示 |
| パス | 隊形の流れを作って時間制御で実行。プレビュー |
| 群制御 | 俯瞰カメラ + AprilTag で位置を測り閉ループ制御: クリック移動 / 隊形 / リーダー追従 / 円周回 / 集合 / 分散 / **連結列で移動** / **自動ドッキング・分離** / パス閉ループ |

※ 救助ミッション画面は 11/26 に外した (`mission.js` はファイルだけ残っていて読み込んでいない)

### 連結走行のしくみ (`coupler-core.js` / `coupler.js`)
- どの号機でも、どの順でも連結できる: 列を「2-1-3」「3-1, 2」のように指定
- ヒンジ連結 (首振り): トラクタ・トレーラの拘束式で、後ろの機体を前の機体のピンの動きに合わせて走らせる
- 固定連結: 塊を1つの剛体として各車輪の速度を計算
- 折れ角はカメラがあれば測定、なければ指令から推定。折れすぎで自動減速
- 自動ドッキング: 後ろの機体が前の機体の後ろピンへ真っ直ぐ寄ってロック

### コントローラー (`gamepad.js`) — Switch Pro / Xbox / PS
| ボタン | 動作 |
|---|---|
| Lスティック | 走る |
| Rスティック | 旋回だけ |
| 十字キー | 一定速度で前後・その場旋回 |
| ZR / ZL | 押している間 最高速 / ゆっくり |
| L / R | 操作する機体を切り替え |
| B / HOME / キャプチャ | 停止 |
| X / Y | 連結器 ロック / 解除 |
| A | 速度 40→70→100% / 停止中は 1.2 秒長押しで再開 |
| Rスティック押し込み | カメラ表示切替 |
| + / − | 画面切替 |

画面右上の「コントローラー」または `?` キーで、実物写真の上に割り当てを重ねた図を表示

### 安全・災害現場向け (`field.js` ほか)
- **STOP**: 黄色い台座に赤いキノコ (ISO 13850 の配色)。押した瞬間に全台停止して「停止中」でロック、再開は 1.2 秒長押し
  ※ 画面の STOP は安全装置ではない。本当の非常停止は電池のスイッチ
- 準備状態を常時表示 (準備OK 3/3 ・ 一部接続 ・ 未接続)
- 通信途絶 (1.5 秒受信なし) → 号機ボタンが赤く点滅 + 警報 + 音・振動。警報は「確認」まで点滅
- 予期しない切断は自動で再接続 (最大15回)
- 操作記録 (接続・切断・停止・再開・警報) を CSV で保存
- 手袋・屋外モード: 画面を大きく、白黒はっきり

### デザイン
- 約100件の操作画面を調査して決めた (一覧と根拠: `docs/ui-research.md`)
- 背景はグレーの層、色は状態と号機だけ、つや消しの質感
- 書体: 和文ヒラギノ角ゴ、ボタン・数字は DIN
- ロボットは田宮キャタピラ風の絵 (前のライトバーと矢印で進行方向がわかる)

## 4. 検証したこと
| 内容 | 結果 |
|---|---|
| 連結走行シミュレーション (`node app/test/coupler-sim.test.js`) | 連結部の引きずり 29.6 → 2.3 cm/s。従来方式は列が 180° 折れる |

| STOP / 長押し再開 | 短押しでは再開しない、1.2 秒で再開 |
| 画面 | 各タブ・スマホ幅・コントラスト比を確認 |

## 5. まだ確認できていないこと
- 実機への書き込みと走行 (連結走行・ドッキング・自動再接続・通信途絶の警報を含む)
- サーボのロック角・解除角、寸法 (トレッド・ピン距離)、最高速の実測 → アプリの「寸法・補正」に入力
- Switch Pro を Mac の Chrome につないだときの実際のボタン番号
- 1号機カメラの映像
- ESP32 が発熱して壊れた件の原因 (USB と電池の同時接続 / TB6612 故障 / ショートが候補)
