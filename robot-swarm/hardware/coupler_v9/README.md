# 連結器 coupler_v9 (3機共通)

どの号機どうしでも、どの順番でも連結して一緒に走るための連結器です。

## 部品 (STL)
| ファイル | 寸法 (mm) | 内容 |
|---|---|---|
| `01_hook_unit.stl` | 75.5 × 60 × 37 | フック本体 (サーボ付きゲートで相手のピンを保持) |
| `03_fork.stl` | 100.5 × 64 × 68 | フォーク (相手のフックが掛かる側) |
| `02A_gate_spline4.6/4.7/4.8.stl` | 24 × 15 × 14 | サーボ軸に挿すゲート。スプライン径違い 3種 |
| `11_spline_fit_test.stl` | 50 × 10 × 4 | スプライン径の合わせ用テストピース (先にこれを印刷) |
| `08_long_pin_x28.stl` / `10_long_pin_clip_x28.stl` | — | ピン と 抜け止めクリップ (28組) |
| `09_servo_pin_long_x2.stl` | — | サーボ用ピン (2本) |

各ロボットに **前 = フォーク / 後ろ = フック** のように同じ向きで付けると、どの機体の後ろにもどの機体が付けられます
(逆向きに付けた場合はアプリの「サーボ付きフックの位置」を「前」に)。
`11_spline_fit_test` で手持ちのサーボ (SG90 系) にきつめに入る径を選び、その `02A_gate_spline` を使います。

## 配線 (全機共通)
| 機体 | サーボ信号 | サーボ電源 |
|---|---|---|
| 2号機・3号機 (ESP32 DevKit) | GPIO27 | 5V (電池側) |
| 1号機 (XIAO ESP32S3) | D7 | 5V (電池側) |

- **サーボを ESP32 の 3V3 から給電しない**。電圧降下で BLE が切れたり、発熱の原因になります。GND は共通。
- サーボ電源の根元に 470µF 程度のコンデンサを推奨。
- ファームは動かした 0.7 秒後に PWM を止めます (ゲートは機構で保持)。

## 使い方
1. 各スケッチ (`esp32/*/`) を書き込む。`SwarmCoupler.h` が同じフォルダにあることを確認。
2. アプリ 🎮操作 → **🔗 連結** → 寸法 → サーボ角「1号機で試す」で ロック角 / 解除角 を合わせる。
3. 列を「2-1-3」のように指定 (前→後ろ、「,」で別の列) して ロック → スティックで走行。
4. 俯瞰カメラがあれば 🛰群制御 → **自動ドッキング** / **連結列で移動** が使えます。
