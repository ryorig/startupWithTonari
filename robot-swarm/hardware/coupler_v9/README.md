# 連結器 coupler_v9 (3機共通)

どの号機どうしでも、どの順番でも連結して一緒に走るための連結器です。

## 部品 (STL, v9.1)
| ファイル | 内容 |
|---|---|
| `01_hook_unit.stl` | フック本体。**サーボ MG90S を下から入れる**。門 (ゲート) が横棒の前をふさいでロック |
| `02A_gate_spline5.0/5.1/5.2.stl` | サーボ出力軸 (20歯 φ4.9) に直接はめる門。`11_spline_fit_test` で径を選ぶ。前面を下に・充填 100% |
| `03_fork.stl` | 受け側 (横棒)。サーボなし |
| `08_long_pin_x26` / `10_long_pin_clip_x26` | 取付けピンとクリップ (フック側 12・フォーク側 14) |
| `09_servo_pin_long_x2` | サーボの耳を留めるピン |
| `11_spline_fit_test` | はめ合い試験 (φ4.9〜5.3) |

設計の詳細・検証結果は [DESIGN.md](DESIGN.md)。サーボがあるのは**フック側だけ**。1号機はフック側。

## サーボ角度
- 閉じる (ロック) = **90°**、開く (解除) = **45°** (門は 40° で横棒の通り道から出る)
- 取り付け: サーボを 90° にしてから門を押し込み、付属の小ねじで留める (シリアルモニタで `K1`)
- 開く向きが逆なら `SwarmCoupler.h` の `COUPLER_UNLOCK_DEG` を 135 にする
- 引っ張られたままでは開かない (摩擦)。外すときは止まってから

## 配線 (全機共通)
| 機体 | サーボ信号 | サーボ電源 |
|---|---|---|
| 2号機・3号機 (ESP32 DevKit) | GPIO27 | 5V (電池側) |
| 1号機 (XIAO ESP32S3) | D7 | 5V (電池側) |

MG90S の線の色: **オレンジ = 信号**、**赤 = +5V**、**茶 = GND**

- **サーボを ESP32 の 3V3 から給電しない**。電圧降下で BLE が切れたり、発熱の原因になります。GND は共通。
- サーボ電源の根元に 470µF 程度のコンデンサを推奨。
- ファームは動かした 0.7 秒後に PWM を止めます (ゲートは機構で保持)。

## 使い方
1. 各スケッチ (`esp32/*/`) を書き込む。`SwarmCoupler.h` が同じフォルダにあることを確認。
2. アプリ 🎮操作 → **🔗 連結** → 寸法 → サーボ角「1号機で試す」で ロック角 / 解除角 を合わせる。
3. 列を「2-1-3」のように指定 (前→後ろ、「,」で別の列) して ロック → スティックで走行。
4. 俯瞰カメラがあれば 🛰群制御 → **自動ドッキング** / **連結列で移動** が使えます。
