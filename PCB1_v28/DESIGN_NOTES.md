# PCB1 v28 — 幅 10.0 mm・MAX30101 版（v27 を縦に詰めた版）

- `PCB1_v28.epro2`：EasyEDA Pro でインポートするファイル
- `layout_top_bottom.png`：表面と裏面の図（緑＝GND ベタのシミュレーション）
- `tools/`：生成（`design.py` + `route14.py`）と検証（`drc.py`）のスクリプト

## 仕様
| 項目 | 値 |
|---|---|
| 外形 | **10.00 × 19.44 mm**（先端の半島を含む。v27 は 10.00 × 20.0 mm、v26 は 10.16 × 24.4 mm） |
| 層 | 2 層、1.6 mm、1 oz |
| 部品 | MAX30101EFD+T（LCSC C2859066）、TMP117、XC6206（1.8 V）、0402/0603 受動部品、JST SH 4 ピン |
| INT | 1 ピンヘッダー（P1）を廃止。はんだ付け用テストポイント（穴 0.5 mm、表側のみマスク開口） |
| 配線 | ほぼ表面のみ。裏面は INT と、プルアップ用の 3V3 の 2 本だけで、ほかは GND ベタ |

## v27 からの変更（部品はそのまま、表面実装のみ）
- C5（10 µF）を MAX30101 の左横へ移動。VLED は本体の下で 9–10 番ピンをつなぎ、左端から C5 へ出す
- LDO（U3）と C3 を上げ、C3 を VOUT と GND の横に置いた
- 3V3 の幹線を左端（x = 0.56 mm）に寄せ、C2 を幹線の上に置いた
- プルアップ R1/R2 とコネクターを 0.57 mm 上げた（R1 と TMP117 の中心間は 10.0 mm を維持）
- 0402 部品の GND 側の配線を 10 mil にして、熱バランスの比を 2.5 以下にそろえた

## プロの基板から取り入れたこと
| 手本 | 内容 | この基板 |
|---|---|---|
| SparkFun MAX30101 基板（2 種）・MAX30105 | センサーの長辺を基板の辺に平行に置く。パッド列の間（本体の下）に配線を通し、中央に GND ビアを置く。10 µF / 0.1 µF はセンサー中心から約 3 mm 以内 | 長辺を幅方向に置く。本体の下で PGND と GND を中央ビアで結ぶ（約 2.7 mm）。VLED 9–10 を連結し、SDA を通す。C4/C6 は約 1.1 mm、C5 は本体のすぐ左 |
| SparkFun（INT ビア） | INT をパッケージの端のビアから引き出す | 同じ方式（INT は裏面を通す） |
| Adafruit / SparkFun TMP117 | センサーとパスコンを半島に置き、ベタを置かない。中央パッドなし | 先端の半島に TMP117 と C1 を置く。表裏ともベタを本体から 1.3 mm 以上離す |
| TI SNOA986 | パスコンは 5 mm 以内、プルアップは 10 mm 以上離す | C1 は 0.6 mm（中心間 1.9 mm）。R1 は中心間で 10.0 mm |
| Adafruit / SparkFun（コネクター） | コネクターの開口を基板端にそろえ、本体の下に配線やビアを通す | SM04B を端に置き、3V3 と GND のビアを本体の下に置く |
| JLCPCB | 実装できる最小サイズは 10 × 10 mm | 幅 10.00 mm |

## 検証結果
- **自作の検証スクリプト**：帰路の 3 件（下記）以外は違反 0 件（間隔、パッド内ビア、穴の間隔、基板端、配線幅、90° の曲がり、端点のずれ、部品間隔、熱バランス、シルク）
- **GND**：裏面のベタは 1 枚につながっている（ベタの隙間を 10 mil / 20 mil の両方で計算）
- **独立レビュー**：別のエージェントが独自スクリプトで確認。間隔・パッド内ビア・端点・角度・接続・ネットリスト・部品間隔はすべて合格。指摘された「肩の部分でベタが基板端に近い」点は修正済み（ベタを 15 mil 下げた）。判定は「発注してよい」

## 意図的に残している点・注意点
| 項目 | 内容 |
|---|---|
| 帰路 | 次の区間は、反対の面に GND ベタがない（いずれも短い）<br>・SDA 約 1.7 mm、SCL 約 1.4 mm：熱分離のためにベタを抜いた境目と、裏面の 3V3 配線をまたぐ部分<br>・INT 約 4.0 mm（v27 は 1.5 mm）：裏面の INT が表面の 3V3 配線の下を通る区間。3V3 はパスコンで交流的に GND とつながっており、INT は状態の変化が少ない割り込み信号なので影響はほぼない |
| プルアップの距離 | R1 は TMP117 から中心間で 10.0 mm、部品の端どうしでは約 8.2 mm |
| 半島 | 幅 5.8 mm でつながっている（切り欠きスロットなし）。代わりにベタを大きく下げた |
| コネクター | SM04B（高さ 2.95 mm）がセンサーと同じ面にある。ケース設計で、センサー面が肌に当たるように逃がす |
| ESD | ケーブルの信号線に ESD 保護素子はない |
| シルク | 受動部品の外形線は省略。部品番号は 7 個表示し、4 個（C1, C6, CN2, R3）は非表示 |

## 発注時の注意
1. EasyEDA でインポートしたら、**ベタの再生成（Shift+B）をしてから DRC** を実行する
2. Via Covering は **Tented**（パッド内ビアなし）。INT のテストポイントだけは表側のマスクを開けている
3. 幅 10.00 mm は JLC の実装最小サイズちょうどなので、**パネル化（Panel by JLCPCB）＋エッジレール**で発注する
4. 表面処理は ENIG を推奨
5. 実装後、MAX30101 用のライブラリ（SparkFun MAX3010x など）で動作を確認する。LED 電流は 30 mA 程度以下から試す（VLED は 3.3 V 給電のため）

## 再生成の方法
`tools/` のスクリプトは、テンプレートとして PCB1_23 の `PCB1.epru` を使う。
1. `max30101_device.txt` と `max30101_symbol.txt` を、`tools/` の 1 つ上のフォルダーに置く
2. 次を実行する：`python3 tools/design.py <PCB1_23 の PCB1.epru> out.epru route14.py`
3. 検証は次で行う：`python3 tools/drc.py out.epru out.png`
