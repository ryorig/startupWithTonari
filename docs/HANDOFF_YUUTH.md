## 3. デザイン方針（決定事項と経緯）

### 3-1. 色
| 用途 | 色 | メモ |
|---|---|---|
| メイン（押せる所・リンク） | `#1592D0` | エアウォレット系の水色 |
| 濃いめ（押下・強調文字） | `#0F7FB5` | |
| ヘッダー帯・ハイライト | `#1CB1E5` | |
| 薄い水色面 | `#E1F3FB` | |
| サブ（青緑） | `#0E8F84` / 薄 `#DDF3F1` | 黄緑の代わり |
| 注意・「自分」 | オレンジ `#EE7A1F` | |
| 背景 / 文字 / 補助文字 | `#F3F4F6` / `#333333` / `#6B7280` | 小さい文字はコントラスト4.5以上 |
| アバター等のアクセント | 自分=オレンジ、学生=青緑、企業=`#5B6B7A`、コミュニティ=`#E5574A`、公式=`#D69A12` | |

- **NG**: 紺（既存 lp.css の `--brand:#213a89` 系）、黄緑、紫。※既存サイトはまだ紺を使っている → Yuuthサイトでは使わない方針でよいか、**着手前に本人へ一度確認**。
- ロゴ画像（assets/logo.png 等）は**そのまま使う**。色を合わせるためにロゴを加工しない。

### 3-2. 文字
- 見出し: **IBM Plex Sans JP SemiBold(600)**（自作フォントは不評で撤回済み）
- 本文: Noto Sans JP / 英字: Inter、ロゴ周りの英字: Kumbh Sans
- サイズ段階: 11 / 13 / 15 / 17 / 20 / 28 px、余白は4の倍数、角丸 12 / 16 / ピル

### 3-3. 参考にしたもの・ユーザーの好み
- 好評: **AirWallet（エアウォレット）** の配色・雰囲気、Adobe・LINE公式アカウントの画面構成
- 不評: 派手なアクセント色（「気色悪い」）、ミイダス風、空いた余白が多い、安っぽさ、3D図形の多用
- イラスト: **Humaaans（CC0・商用可）**。他社イラストのコピーは不可
- アイコン: Phosphor Icons
- 「リサーチを共有してから作る」「最後に検証を入れる」が基本の進め方
