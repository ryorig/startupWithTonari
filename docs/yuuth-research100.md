## 横断分析

### 1. トップページのセクション構成 上位3パターン (h1〜h3順から分類, 見出し取得できた約90件)
1. **事業会社型 (約35件)**: FV(ミッション1文) → About/Mission → Business/Service → News → Recruit → Contact。例: SmartHR, Ubie, HRBrain, プレイド, タイミー, Techouse, Visional, ログラス, LayerX, エクサウィザーズ。
2. **SaaS/LP型 (約30件)**: FV(価値+CTA2つ) → 導入ロゴ帯 → 課題/機能3〜4点 → 導入効果数字 → 事例 → 料金/資料請求 → FAQ。例: freee, kickflow, Helpfeel, ベースマキナ, LegalOn, Nint, 海外SaaS全般。
3. **受託・制作会社型 (約15件)**: FV(スローガン) → Works/事例 → Service(工程) → 会社/メンバー → News → Contact。例: ソニックガーデン, グッドパッチ, Sun*, ゆめみ, もばらぶ, thoughtbot, ustwo, Instrument, netguru。→ **Yuuthはこの型＋SaaS型のCTA設計が最適**。

### 2. 小さな会社の「信頼感」手法 (102ページ中のキーワード検出数)
- 導入事例/Works: 67 / 数字実績(累計・社数・No.1): 34 / 会社概要: 53 / 受賞・認定・選出: 48 / 取引先ロゴ: 47 / ニュース(更新頻度): 91 / 採用: 87 / 代表メッセージをトップに出す: 8 (少数。代表の顔と名前は会社ページ側が主流)
- 有効な具体例: ソニックガーデン「数字で見る」セクション、テックジム「8年で2万人」、kickflow「東証プライム企業採用」バッジ、ガイアックス「起業家輩出」を社是に。小規模でも「対応件数・継続率・平均納期」など出せる数字を3つ並べるのが定石。
- 学生起業はメディア掲載ロゴ・コンテスト受賞・高専名/提携先を「Featured in」帯で出すと補える。

### 3. 水色系 (#1592D0 付近) メインサイトの配色
- 該当: SmartHR #00c4cc, atama+ #0095aa, 高専機構 #009fbc, もばらぶ #2193b0, スタディスト #25b0e5, ゆめみ #00c8ff, Figma #00b6ff, Sansan #0b72c8, グッドパッチ #096fc8, Chatwork #007fab (青寄り: Basecamp, Dropbox, freee)。
- 面積比の傾向: 白/極薄グレー 70〜80% : 本文墨色(#222〜#333) 10〜15% : メイン水色 5〜10% : アクセント 1〜3%。水色はFV見出しの一語・ボタン・アイコン・細い罫線に限定し、面で敷くのは「背景に10%程度の淡色 (#e5f4ff, #e7f3fc, #dfeef0)」で区切る使い方が主流。
- アクセント: 暖色1色だけを点で使う (SmartHR赤 #ee3123、atama+黄 #ffe800)。CTAは水色塗り白文字 or 濃色。#1592D0 は白文字とのコントラストが約3.6:1で本文AA未達 → ボタン文字は太字16px以上、本文リンクは #0E6FA0 程度に暗くする。
- NG例として: 紺主体 (NRI #00196e, ガイアックス #002554), 紫 (LayerX #534dff, スタディストの #8255cd 併用), 黄緑 (ソニックガーデン #46c82d)。

### 4. ヘッダー/フッター/CTA の定石
- ヘッダー: 左ロゴ / 中央〜右に4〜6項目 (About, Service, Works, News, Recruit, Company) / 右端に塗りボタン「お問い合わせ」(SaaSは「資料請求」+「無料相談」の2つ)。スクロールで固定・白背景化。
- フッター: 濃色または淡色背景、サイトマップ列、会社名・所在地、プライバシーポリシー、SNS。直前に全幅CTA帯 (「まずは相談」) を置く型が受託/SaaSでほぼ共通。
- CTA: 1ページに同じ文言のCTAを3回 (FV・中盤・フッター前)。「無料」「30秒」「オンライン」など負担を下げる補足を添える。

### 5. スマホ表示の工夫
- 約4割でハンバーガー検出。メニューは全画面オーバーレイ＋下部に問い合わせボタン。
- FV見出しは2〜3行に収まる短文、改行位置指定。横並びカード→縦積み、ロゴ帯は横スクロール/自動ループ。
- 画面下固定のCTAバー (SaaS・教育系 atama+, テックキャンプ等で多い)。電話番号タップ発信。

### 6. 避けるべき点 (安っぽく見える要素)
- フリー素材の握手・PC前笑顔写真、意味のないスライダー自動切替。
- 色数過多・グラデーション多用・影の強いボタン。WordPress既定色 (#32373c等) がそのまま残るテーマ感。
- 中身のないNews (最終更新が1年前)、「準備中」ページ、根拠なし「No.1」。
- 字間の詰まった全角英数、本文12px以下、見出しの字形混在。
- 実績ゼロを隠すための抽象コピーだけのFV — 小さくても具体 (誰に・何を・何日で) を書く。
